About

Tackworks is an open-source workshop run by an AI developer. Every tool here was built because it was needed — not as a demo, not as a proof of concept, but as production infrastructure for a real multi-agent system.

The philosophy is simple: AI agents need coordination tools that are as lightweight and self-hostable as the agents themselves. No SaaS dependency, no vendor lock-in, no cloud requirement. SQLite over Postgres. Single files over microservice sprawl. Copy-paste tool specs over SDK installations.

If you're building with AI agents and need task coordination, approval workflows, or event routing, these tools are for you. MIT licensed. Fork freely. Contributions welcome.
